# Локальная проверка карты

Этот сценарий использует отдельный стек для проверки карты. Обычная остановка приложения кнопкой Stop в IDEA сохраняет данные и контейнеры. `stop-map-review.ps1` выполняет явное удаление контейнеров и их volumes, поэтому используйте его только для сброса проверочного стека. Другой стек на стандартных портах описан в [инструкции постоянного локального запуска](../../docs/operations/local-ingestion.md).

Для запуска не нужен `.env`: все несекретные локальные параметры уже записаны
в shared-конфигурациях IDEA из каталога `.run`.

Spring автоматически загружает GDELT и сам создает поисковые индексы. Скрипт не подставляет пустой индекс вместо настоящих данных. При переходе со старого сценария он отключает от поиска только известную пустую заглушку, предварительно проверив отсутствие документов; сам индекс, база и скачанные файлы сохраняются. Если заглушка содержит документы или проверка не завершилась, запуск останавливается без изменения ее привязки.

1. Если review-контейнеры еще не запущены, выполнить из корня проекта:

   ```powershell
   .\tools\map-review\start-map-review.ps1
   ```

2. В IDEA выбрать конфигурацию `Event Mosaic Local` и нажать `Run`. Она выполняет Gradle `bootRun`: собирает frontend при изменениях и запускает Spring Boot с картой и API на порту `18080`. Подготовленный Node.js из `.local/node-v24.19.0-win-x64` находится автоматически, править PATH не нужно. Отдельный Vite не запускается.

3. После строки `Started EventMosaicApplication` открыть <http://127.0.0.1:18080>.

   На пустом хранилище данные временно недоступны, затем появляется частичное и полное покрытие суток. После первой загрузки обновите страницу вручную, чтобы не ждать штатного 15-минутного обновления карты.

4. Остановить `Event Mosaic Local` кнопкой Stop в IDEA. Для продолжения достаточно снова Run; контейнеры, индексы и `.local/gdelt` сохраняются. После правок frontend Stop/Run автоматически собирает новую версию. Для мгновенного обновления интерфейса можно дополнительно запустить `Event Mosaic Frontend` и открыть <http://127.0.0.1:5173>.

5. Только если проверочный стек и его данные больше не нужны, после остановки приложения выполнить:

   ```powershell
   .\tools\map-review\stop-map-review.ps1
   ```

Start-скрипт поднимает отдельный Docker Compose-проект
`event-mosaic-map04b-review`: PostgreSQL доступен на порту `15432`, а
Elasticsearch - на `19200`. Его контейнеры, сеть и volumes не пересекаются с
обычным локальным стеком. Stop-скрипт удаляет целиком только этот review-стек и
его временные данные.
