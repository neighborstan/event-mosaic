# Event Mosaic

Event Mosaic - приложение для загрузки, обработки и отображения событий GDELT на карте.

## Стек

- Java 25
- Spring Boot 4.1.0
- Gradle 9.5.1
- PostgreSQL
- Flyway
- Elasticsearch

## Инфраструктура

Локально:

```shell
docker compose -f compose.local.yml up -d
```

## Эксплуатационные операции

- В приложении уже есть механизм, который заново собирает поврежденный фрагмент
  поисковых данных и безопасно переключает поиск на исправленную копию. Сейчас
  он доступен только через аварийную серверную команду; для будущей админки
  нужно добавить защищенный endpoint и экран управления. [Инструкция для
  разработчика и администратора](docs/operations/partition-rebuild.md).
